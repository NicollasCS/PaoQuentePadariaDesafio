# Manual da equipe — Pão Quente

## Abrir o painel

1. Inicie a aplicação e acesse `http://localhost:3000/admin.html`.
2. Informe o usuário e a senha da equipe.
3. Clique em **Sair** ao terminar.

## Consultar pedidos

Na aba **Encomendas**, veja o nome e telefone do cliente, os produtos, as quantidades, o total e o horário de retirada. Leia também as observações.

## Atualizar o status

Escolha o status apropriado no pedido:

- **Pendente**: recebido.
- **Em preparação**: sendo feito.
- **Pronta para retirada**: pronto para o cliente buscar.
- **Finalizada**: já foi retirado.
- **Cancelada**: não será preparado.

Para localizar um pedido pronto, confira o status **Pronta para retirada**.

## Produtos

1. Abra a aba **Produtos**.
2. Preencha nome, descrição, preço, categoria e URL HTTPS da imagem para cadastrar.
3. Clique em **Editar** para alterar um produto e salve.
4. Clique em **Excluir** para remover o produto do catálogo e confirme.

Um produto excluído não aparece mais para clientes. Os pedidos antigos continuam guardados.
